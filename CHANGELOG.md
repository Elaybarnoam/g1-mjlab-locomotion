# Changelog

All notable changes are documented here. The format follows Keep a Changelog and releases use
semantic versioning.

## [Unreleased]

- Walking, perturbation robustness, domain randomization, and deployable state estimation remain
  future milestones.

## [0.2.0] - 2026-09-11

### Added

- Checksum-pinned `standing-v1` inference bundle installation.
- One-command deterministic playback for an installed policy.
- A deterministic release builder for the ONNX policy bundle and separate trusted resume
  checkpoint.
- Public policy usage, redistribution, integrity, and simulation-only safety documentation.

## [0.1.0] - 2026-09-10

### Added

- Versioned Unitree G1 standing-v1 task and PPO training workflow.
- Deterministic held-out evaluation with strict standing and survival metrics.
- Native MuJoCo/ONNX evaluation, transfer parity checks, video recording, and interactive playback.
- Content-addressed checkpoints, contracts, source snapshots, evidence, and offline HTML reports.
- Three-seed standing evidence and an untouched 100-trial final qualification.
