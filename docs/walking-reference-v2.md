# Walking reference semantics v2

Reference semantics v2 corrects four demonstrated host-side defects without changing the
102/114/29 actor, critic, or action layouts. Any checkpoint continued with these semantics is a
fine-tune, not an exact resume of its historical trajectory.

## Time and velocity

The source clip moves at 1.163811593 m/s and contains 53 intervals over a 1.06 s cycle. For applied
speed `v`, phase advances at `v / (source_speed * cycle_duration)` cycles/s. The source spatial path
is retained, source velocities are multiplied by `s = v/source_speed`, and accelerations by `s²`.
The derivative of the blended target is:

```text
q_des = (1-b) q_nominal + b q_reference
qdot_des = b s qdot_reference + bdot (q_reference - q_nominal)
```

`bdot` is measured from the actual rate-limited blend update. A zero-dt reset has zero blend
velocity and does not advance command, phase, blend, or reference distance. Reference-initialized
root and joint velocities use the same time scale.

The retargeted raw sole path reaches 0.02724 m below the terrain plane. Semantics v2 therefore adds
0.030 m to the root height only when writing a reference-initialized physical state. It does not
alter relative body targets. Schema-1 host behavior remains selected when no versioned walking
profile is supplied.

## Manager timeline

The pinned mjlab manager executes one control interval in this order:

1. The actor reads observation `k`, including applied command and phase `k`.
2. The action is applied for four 0.005 s physics steps.
3. Terminations and rewards read physical state `k+1` with command/phase `k`.
4. Terminal resets and reset events run.
5. The command manager advances exactly once; reset worlds receive `dt=0`.
6. Observation `k+1` is built with the newly advanced command/phase.

Consequently, expected contact for a reward refers to the phase that generated the just-completed
action interval. Reward reads never mutate or advance phase. The ordering is covered by a real GPU
manager test.

## Frames and randomization

The command is yaw-heading aligned. Semantics v2 compares it with world velocity rotated by pelvis
yaw only; roll and pitch no longer contaminate forward speed. Schema 1 retains the historical full
body-frame comparison for reproduction.

Phase randomization now samples a tensor and explicitly assigns selected environment indices. The
old advanced-index in-place call modified a temporary. Indexed-reset tests prove untouched worlds,
nonconstant draws, and seeded reproducibility. Reference initialization, phase randomization,
domain randomization, and actor observation noise are separate profile controls.

## Feasibility result

[`reference-map-v2.json`](../configs/walking-v1/reference-map-v2.json) is generated by
`scripts/audit_walking_reference.py` from the immutable motion, pinned G1 XML, and captured
controller contract. XML hashing normalizes CRLF to LF so Windows checkouts preserve the manifest
identity. The audited 0.4/0.6/0.8 m/s cadence targets are approximately 0.6485/0.9727/1.2970
steps/s. Step and stride targets remain approximately 0.6064/1.2128 m because this transformation
changes time, not space. All three speeds pass the current kinematic, joint-limit, terrain-clearance,
and actuator-demand checks. This is reference feasibility, not evidence that a learned policy walks.
